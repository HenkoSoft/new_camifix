# CAMIFIX Landing

Landing page premium para CAMIFIX, servicio técnico online especializado en reparación de celulares y notebooks.

## Estructura

- `app/`: App Router, metadata SEO, página principal, Open Graph dinámico y estilos globales.
- `components/site/`: secciones de la landing.
- `components/ui/`: componentes reutilizables pequeños.
- `lib/`: datos mock del negocio, servicios, testimonios y utilidades.

## Comandos

```bash
npm install
npm run dev
npm run build
```

El objetivo de conversión es únicamente generar consultas por WhatsApp.
